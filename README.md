# 2026-AI-App-minheak
AI 앱 개발 해커톤 2차

# 🥗 HealthyFood AI
음식 사진을 분석하여 건강 문제점을 파악하고, 더 건강한 식단과 조리법을 제안하는 AI 서비스입니다.

## 🛠 사용 기술
- Python, Streamlit
- Google Gemini 1.5 Flash (AI 분석)
- Pollinations AI (이미지 생성)

## 🚀 실행 방법
1. 구글 AI 스튜디오에서 API 키 발급
2. `.streamlit/secrets.toml` 파일에 키 설정
3. `pip install -r requirements.txt` 실행
4. `streamlit run app.py` 실행
